## Featured projects

### [Pictorial Translate](https://github.com/Anmol-Shrestha/aws-image-text-speech)

Upload a photo of a sign, menu, or label. It finds the text, translates it into English, and reads it aloud. Built with Chalice on AWS Lambda, S3, Rekognition, Translate, and Polly, with Clerk for sign-in.

Live site (invite-only): https://main.dvsybtsoulkw3.amplifyapp.com

### [VybeBackend](https://github.com/Anmol-Shrestha/VybeBackend)

A restaurant discovery backend that uses semantic search (RAG) to find restaurants from a natural-language query. It includes an MCP server that connects to Claude Desktop.
